# 🤖 AI Feature Spec — Home Page

---

## Feature Identity

- **Feature Name:** Home Page
- **Related Area:** Public-Facing Page / Personal Introduction
- **R1 Reference:** Section "Feature - Home page"
- **Spec File:** `./ai/features/home-page.feature.md`

---

## Feature Goal

Build the public landing page at the root URL (`/`). The page presents Damien McCullor's name and professional identity, a curated set of technical and soft skills with icons, and at least two AI-generated images — all organized into at least 3 visually distinct sections.

---

## Feature Scope

### In Scope (Included)

- `src/pages/Home.jsx` — replaces the current stub with full content
- `src/pages/Home.css` — page-specific styles
- Introduction section: name, role/tagline, and introductory paragraph
- Technical skills section: at least 3 skills, each with supporting text and an inline SVG icon
- Soft skills / talents section: at least 3 skills, each with supporting text and an inline SVG icon
- At least 2 AI-generated images integrated into the page with `alt` text
- LOGIC BRIEFING and SECTION comments on `Home.jsx`

### Out of Scope (Excluded)

- Resume/CV download — belongs to `portfolio-page` feature
- Contact form — belongs to `contact-page` feature
- Project/portfolio entries — belongs to `portfolio-page` feature
- Back Office or authentication logic

---

## Sub-Requirements (Feature Breakdown)

- **SR-1 — Root Path** — Home page renders at `/#/` (HashRouter root). It is the default landing page when the site is visited with no hash.
- **SR-2 — Introduction section** — Contains Damien's full name in a prominent heading, a role/title or tagline, and a brief introductory paragraph describing who he is.
- **SR-3 — Technical skills section** — At least 3 technical skills displayed. Each card/item includes: a skill name, supporting descriptive text (not just a single word), and an inline SVG icon representing the skill.
- **SR-4 — Soft skills / talents section** — At least 3 soft skills or personal talents displayed. Same structure as technical skills: name, descriptive text, and an inline SVG icon.
- **SR-5 — Visual layout** — At least 3 distinct sections (e.g., Introduction + Technical Skills + Soft Skills). Sections are visually separated using spacing, background color differences, or dividers.
- **SR-6 — AI-generated images** — At least 2 images generated by an AI tool are placed in `src/assets/` and rendered in `Home.jsx` with non-empty `alt` attributes. The AI tool used must be documented in Tech Constraints below.
- **SR-7 — Responsive** — All sections stack vertically on mobile (≤768px). No horizontal overflow. Images scale within their containers.

---

## Tech Constraints (Feature-Level)

- **Icons:** Use inline SVG icons only — do not import an icon library for individual icons (lessons-learned rule). Each skill icon must be a short inline `<svg>` block.
- **Images:** AI-generated images must be saved in `src/assets/` and imported in `Home.jsx`. Minimum 2 images. Document the AI tool used here: `[AI tool: Gemini — images generated from scratch, no copyright concerns]`.
- **Colors:** All color values from `src/constants/brandColors.js`. No hardcoded hex values.
- **LOGIC BRIEFING:** Required on `Home.jsx`.
- **`<main>` landmark:** Content already wrapped by `Layout.jsx` — no additional `<main>` needed inside `Home.jsx`.
- **Responsive:** Section containers must use `flex-direction: column` or stack naturally at ≤768px. Images must have `max-width: 100%`.

## Runtime User Flow

1. Visitor navigates to `https://damien-mccullor.github.io` or `/#/`.
2. The Home page renders inside the Layout (Header + Footer visible).
3. The visitor sees Damien's name and tagline in the introduction section at the top.
4. Scrolling down, the visitor sees the technical skills section with at least 3 skill cards, each showing an icon, name, and description.
5. Continuing to scroll, the visitor sees the soft skills / talents section with at least 3 items in the same format.
6. AI-generated images are visible inline within the relevant sections, with descriptive alt text.
7. On mobile, all sections collapse to a single column and images scale to fit the viewport.
